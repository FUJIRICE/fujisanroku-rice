## 2. 収集する情報 / Data We Collect

本サービスは、以下の限られた情報のみを取り扱います。

We only handle the following limited data:

- **SNS API連携データ**: Pinterest、TikTok、Instagram、Facebook、Threads、X（Twitter）などの各APIを通じて、自社コンテンツ（農場の写真・動画）を投稿・管理するために必要な**アクセストークン**のみを使用します。ユーザーの個人情報は収集しません。
- **お問い合わせ情報**: メール等でご連絡いただいた場合、返信に必要な範囲（お名前・メールアドレス）のみを使用し、目的達成後は削除します。
- **アクセス解析**: Cloudflare Pages の基本アクセスログ（IPアドレス、アクセス日時）が自動収集されますが、個人を特定する目的には使用しません。

We use **access tokens only** from social media APIs (Pinterest, TikTok, Instagram, etc.) to post our own farm content. We do not collect personal information from visitors.

**保持期間 / Retention period:** APIトークンはサービス継続に必要な期間のみ保持します。お問い合わせデータは目的達成後、最大6ヶ月以内に削除します。

## 3. Pinterest API の利用について / Pinterest API Usage

本アプリは **Pinterest API** を使用して、FUJI RICEの農場コンテンツ（写真・動画）をPinterestに自動投稿することを目的としています。

This app uses the **Pinterest API** solely to automatically post FUJI RICE farm content (photos and videos) to Pinterest.

- Pinterestから取得したデータは、投稿管理の目的にのみ使用します。
- Pinterestから取得したコンテンツや派生データを**第三者に販売・提供・再配布することは一切ありません**。
- ユーザーがPinterest連携を解除した場合、関連データは速やかに削除します。
- **本アプリ・ブランドはPinterest社とは独立しており、Pinterestによる推奨・承認・提携関係はありません。**

Pinterest-derived data is used only for content posting purposes. We do **not** sell, share, or redistribute any Pinterest content or Pinterest-derived data to third parties. Upon disconnection, all related data will be promptly deleted.

**This app and brand (FUJI RICE) are not endorsed by, affiliated with, or sponsored by Pinterest.**
