# 販路運用ランブック（BASE本店・Yahoo比較継続）

更新: 2026-07-22。自前集客はBASEへ集約し、Yahooとリベ市場は役割を分けて運用する。

## 現在の役割

- BASE: SNS・YouTube・LINE・公式サイトから集客する本店
- Yahoo!ショッピング: Yahoo内検索とPayPay希望者向け。2026年8月末まで数字を測る
- リベ市場: リベシティ利用者向け。継続する

## リンクの原則

- 媒体別BASEリンクは `/go/buy/base/{媒体}/{掲載場所}` を使う
- 商品ページは `/go/buy/base/site/reserve/{商品コード}` を使う
- BASEの生URLをSNSや公式サイトへ直接置かない
- 汎用リンク `/go/buy` と `/go/buy/main` もBASEへ転送する
- Yahooを案内する場合は `/go/buy/yahoo` を使い、BASEと同格の主ボタンにはしない

## 公開後の確認

1. `/go/buy` がBASEへ302転送される
2. 媒体別URLからBASEへ `utm_source`・`utm_medium`・`utm_campaign` が渡る
3. 予約LPの商品ボタンが対応するBASE商品へ移動する
4. スマートフォンで商品選択から購入手続きまで進める
5. BASEまたはGA4で媒体別流入を確認する

## 2026年8月末のYahoo判定

- Yahoo内からの注文数、粗利、広告・固定費を集計する
- 月間粗利13,200円以上かつ5件以上なら継続
- 月間粗利8,800円未満かつ0〜2件なら縮小・停止を基本線にする
- その中間は9月前に再判定する
- SNS等の自前流入はBASEの媒体別UTMで別集計し、Yahoo評価へ混ぜない

## 注意事項

- Yahooを停止する場合も、注文・予約・レビュー・データを保存してから行う
- 販売先の役割や主導線を変えるときは `_channels.js` と本書を同時に更新する
